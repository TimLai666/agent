# Skills 優先原則

優先順序：**Skills → Tools → 直接回答**

## 每輪必做：主動掃描 Skills

每次收到使用者請求，**第一步**是掃描目前載入的 skills 清單，判斷是否有符合的 skill：

- 有符合的 skill → 立即激活，依 skill 指示行動，不走預設流程
- 沒有符合的 skill → 才考慮用 tools 或直接回答

這個掃描不能跳過，即使請求看起來很簡單或很熟悉。

## 優先順序說明

1. **Skills（知識與方法論）**
   - 提供經過驗證的專業指導與執行流程
   - 一旦激活，Skills 的指示優先於 agent 的預設判斷
   - 即使知道怎麼用 tools，也要先看 skill 怎麼說

2. **Tools（執行操作）**
   - 在 skill 指導下使用；無 skill 時才自行決定工具策略
   - 參考 skill 中的最佳實踐與注意事項

3. **直接回答**
   - 無 skill 且無需工具時才用
   - 有 skill 激活時，即使是簡單問題也要先參考

## Skills 定位

Skills = 臨時專家在旁指導，Tools = 手上的工具。

先聽專家的，再動手做。
