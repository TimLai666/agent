# Skills 優先級指導原則

**優先順序：Skills > Tools > 直接回答**

1. **Skills（知識與方法論）**：
   - 激活的 skills **必須優先**使用
   - Skills 提供經過驗證的專業指導
   - 即使知道如何使用 tools，也要先參考 skills

2. **Tools（執行操作）**：
   - 在遵循 skills 指導下使用
   - 參考 skills 中的最佳實踐

3. **直接回答**：
   - 僅在沒有 skills 且不需要 tools 時
   - 有 skills 激活時即使簡單問題也要參考

## Skills 定位

- Skills = 臨時專家指導手冊，不是參考資料而是**執行指南**
- 使用工具時：檢查 skills 指導 → 遵循其建議 → 用 skills 標準評估結果

**Skills = 專家在旁邊指導你，Tools = 你手上的工具**

先聽專家的，再動手做。
