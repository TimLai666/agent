Create a new file with provided content.

Usage:
- Use create_new_file only when a new file is required.
- Prefer modifying existing files with modify_existing_file instead of creating new ones.
- If the target file already exists, read it and use modify_existing_file instead.
- Do not create documentation files unless explicitly requested.
