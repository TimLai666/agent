## 📝 文檔編寫規範

編寫新文檔時請遵循以下規範：

1. **標題清晰** - 使用描述性標題，避免縮寫
2. **結構完整** - 包含目錄、正文、示例
3. **中文優先** - 面向用戶的文檔使用繁體中文
4. **代碼示例** - 提供實際可用的代碼示例
5. **更新日期** - 在文檔頂部標註最後更新日期
